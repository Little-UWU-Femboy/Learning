# Hello, C#! Welcome, .NET

## What Is .NET

### Under The Hood

This is not a programming language. Instead, this is actually the runtime and tools needed (kinda like the engine). It contains things like:

- The actual runtime for the code
- Prewritten classes that can be used so basic things like connecting to a DB or handling JSON data is remade over and over again
- Contains other applications frameworks (libraries) that are built on top of base .NET to be more specalized versions of it. For example. ASP.NET is a special version of .NET geared more towards web development or Entity Framework Core (EF) for database management.
