# Helix Commands

### Delete

**Delete one character**: *d*

**Delete one word**: *wd*

**Delete line**: *xd*

### Copy

**Copy one character**: *y*

**Copy one word**: *wy*

**Copy line**: *xy*

### Paste

**Paste after**: *p*

**Paste before**: *P*

### Text Select

**Select text**: *v + movement*

**Select word**: *w*

**Select line**: *x*

**Select entire file**: *%*

**Cancel selection**: *;*

**Undo**: *u*

**Redo**: *U*

### Editing

**Start editing**: *i*

**Edit at end of line**: *A*

**Edit at start of line**: *I*

### Movment

**Jump to top**: *gg*

**Jump to bottom**: *ge*

**Jump to any text currently on screen**: *gw*

**File word search**: */*

### Space Commands

**File error/warnings on current file**: *space + d*

**File error/warnings on current project**: *space + D*

**File explore**: *space + e*

**Show documentation**: *space + k*

**Quick fix code actions**: *space + a*

### Surrounding

**Surround by adding**: *ms + any character*

**Remove surround**: *md + character*

**Replace surrounded**: *mr + character*
