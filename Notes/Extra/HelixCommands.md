# Helix Commands

**Delete one character**: *d*

**Delete one word**: *wd*

**Delete line**: *xd*

**Copy one character**: *y*

**Copy one word**: *wy*

**Copy line**: *xy*

**Paste after**: *p*

**Paste before**: *P*

**Select text**: *v + movement*

**Select word**: *w*

**Select line**: *x*

**Select entire file**: *%*

**Cancel selection**: *;*

**Undo**: *u*

**Redo**: *U*

**Append to end of line**: *A*

**Add to start of line**: *I*

**File explore**: *space + e*

**Jump to top**: *gg*

**Jump to bottom**: *ge*

**Jump to any text currently on screen**: *gw*

**File word search**: */*
